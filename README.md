# ⚡ IRIS 3-Second Universal Auto Clicker

A high-performance, feature-packed Windows Auto Clicker that starts clicking **every 3 seconds automatically** when launched.

---

## 🚀 Quick Start (Just Double Click!)

- **`run.bat`**: Double-click this file to launch the Auto Clicker GUI. It immediately activates and starts clicking every 3 seconds!
- **`run_silent.bat`**: Runs the GUI cleanly without a command prompt window behind it.
- **`run_cli.bat`**: Runs the ultra-fast console/terminal version.

---

## ⌨️ Global Hotkeys

| Hotkey | Action | Description |
|---|---|---|
| **`F6`** | **Activate / Deactivate** | Toggle the auto-clicker ON and OFF anytime from any app/game |
| **`F7`** | **Pick Coordinates** | Hover your mouse anywhere on the screen and press `F7` to lock target coordinates |
| **`ESC`** | **Emergency Stop** | Instantly halts clicking immediately |

---

## ✨ Features Included

1. **Automatic 3-Second Left Click on Launch**: Automatically armed and clicking as soon as the `.bat` file is run.
2. **Ultra-HD IRIS ASCII Art**: Displays the full, glowing Subpixel TrueColor IRIS logo at startup in the terminal, plus an in-app `[👁️ ASCII]` button to view the art inside the GUI!
3. **Activate / Deactivate Toggle**: Easily pause and resume anytime using the **F6** key or on-screen button.
4. **Customizable Interval**:
   - Set seconds (e.g., 0.5s, 1s, 3s, 10s, 60s)
   - Set milliseconds (0ms – 999ms)
   - One-click presets: 100ms, 1s, 3s (Default), 5s, 10s.
5. **Mouse Button Selection**:
   - Left Click
   - Right Click
   - Middle Click
6. **Click Types**:
   - Single Click
   - Double Click
7. **Location Options**:
   - **Dynamic Cursor**: Clicks wherever your mouse is currently pointing.
   - **Fixed Coordinates**: Click **Pick (F7)** to target exact screen coordinates (X, Y).
8. **Anti-Detection Random Jitter**:
   - Adds subtle human-like randomization (±0.2s) to bypass automated bot detection.
9. **Audio Feedback**:
   - Gentle system audio beeps when activating (high beep) and deactivating (low beep).
10. **Live Statistics & Countdown**:
   - Total clicks counter
   - Elapsed session timer
   - Real-time countdown timer to the next click
11. **Stay on Top**: Keeps the window pinned above other windows for easy access.
12. **Zero External Dependencies**:
   - Built 100% with Python standard library and Windows `ctypes` (no `pip install` needed, runs immediately on any Windows machine).
