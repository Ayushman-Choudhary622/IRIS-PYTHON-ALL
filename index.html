QUICK INSTALLATION

Run Locally on Windows 10 / 11

# 1. Clone the repository
git clone https://github.com/Ayushman-Choudhary622/IRIS-PYTHON-ALL.git
cd IRIS-PYTHON-ALL

# 2. Install required computer vision & automation libraries
pip install opencv-python mediapipe pyautogui numpy

# 3. Launch any application with its dedicated one-click batch launcher:
cd "IRIS EYE PYTHON" & run_eye_clicker.bat
cd "IRIS AUTO BUTTON CLICK" & RUN_IRIS_AUTOCLICKER.bat
cd "IRIS 3 SEC AUTO" & run.bat
cd "IRIS ASCII ART" & SHOW_LOGO.bat
