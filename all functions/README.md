# 👁️ IRIS // Direct Overlay Keyboard & Scroll Controller

> **Lightweight Direct On-Screen Keyboard & Scroll Overlay for Eye-Tracking, Head-Tracking & Assistive Users**  
> *Types directly into screen placeholders, search bars, inputs, and documents without any internal text box.*

---

## ⚡ Quick Launch

Double-click either launcher script to start:
- **`RUN_ALL_FUNCTIONS.bat`**
- **`run.bat`**

---

## 🎯 What Makes This Different?

1. **Direct Screen Typing (No Internal Text Box)**:
   - When you click or dwell on any key, it **types directly into whatever is active on your screen** (Google Chrome search bar, Notepad, Word, chat placeholder, web input field, or URL bar).
   - There is **no scratchpad/internal box**—keystrokes go straight to your target app.

2. **Overlay on All Screens (`WS_EX_NOACTIVATE`)**:
   - The keyboard stays **Always-On-Top** across any screen or monitor.
   - Built with the Windows `WS_EX_NOACTIVATE` style: **clicking keys never steals focus** from your target text field.

3. **Big, Adjustable & Customizable Key Tiles**:
   - Letter tiles are large by default for easy targeting with eye-tracking or head-tracking.
   - Adjust tile sizes on the fly using the header buttons:
     - **`➖` / `➕`** to scale up or down.
     - Presets: **`Normal`**, **`Large`**, **`XL`**, and **`Massive`**.
   - Fonts, heights, and window size adapt instantly in real time.

4. **Dedicated Big Scroll Buttons**:
   - **`▲▲ SCROLL UP`**: Large button to scroll active web pages and documents upward.
   - **`▼▼ SCROLL DOWN`**: Large button to scroll downward.
   - **`⇞ PgUp` & `⇟ PgDn`**: Page-level jumps.
   - **`⬇ AUTO-SCROLL`**: Hands-free continuous smooth scrolling toggle.

5. **Works with Any Existing Clicker**:
   - Use your existing eye-tracking / blink clicker Python script to click keys.
   - Optionally turn on built-in **`🎯 DWELL`** hover-to-click mode if needed.
   - Adjust opacity (`100%`, `90%`, `80%`) to keep background content visible.
